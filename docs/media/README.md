- 桌面：独立 Windows 浮窗。脚本触发喂饭、摸头、窗口停靠、屏幕停靠、散步和滑行动作；中性背景与演示文档是实际打开的窗口。没有后期合成人物或移动轨迹。

- 隐私：主动看屏幕关闭。新增素材已逐帧或逐张检查，无私人聊天、个人路径、真实账户名、其他应用内容或凭据。
- 缺项：右键指点移动在录制环境中未得到完整可用片段；散步只录到屏幕底部移动，没有拍到任务栏本体。不以其他动画替代这些画面。
- 导出：GIF 为 10 fps、共享调色板、无抖动，宽 600 或 720 像素，单个小于 3 MB；截图保留原始裁剪尺寸。只裁剪、缩放和编码，不改写界面内容。

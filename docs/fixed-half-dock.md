# 固定半身停靠与界面修正

停靠在屏幕左右边后，人物始终保持半身：鼠标靠近、主动搭话、收到回复和输入文字都不会让她跑到屏幕中间。点击人物、托盘里的「打开聊天」和聊天快捷键会打开屏幕内侧的输入条。真正拖动时才解除停靠，普通点击不会触发拖拽。

气泡朝屏幕内侧斜上方展开，带斜向指示尾；输入条、看图提示和专注提示也放在屏幕内侧。透明承载窗位于显示器工作区内，人物使用独立锚点，文字不再被整个窗口的裁剪规则截断。输入框取得键盘焦点后，透明空白仍可点透到后面的应用。

进入边缘采用短缓出动画。人物停靠后不再反复探出、收回，也不再为悬停插入整段惊讶动作。缩放和显示器工作区变化会保留停靠侧；拖拽解除时还原紧凑窗口并保持人物坐标。

其他修正：

- 新动画真正开始播放后才替换旧画面，避免播放失败时人物空白。
- 暂停看图会取消待处理任务，并在截图的异步步骤后重新检查是否仍允许上传。
- 标题优先使用本机幼圆字体，保持深蓝、奶白与暖金色界面；动态页首人物下移，避开关闭按钮。

## 验证范围

纯逻辑测试覆盖半身锚点、重复事件、输入焦点、点击与拖拽区分、缩放、显示器变化、动画交接与截图取消。原生 Electron 检查覆盖左右两侧、60%/160%/当前尺寸的六种组合，确认主动回复和输入时人物不移动，气泡与输入条完整入屏，透明中部可点透；同时检查标题字体和页首人物位置。

原生检查中的回复和鼠标通知为模拟数据，没有为测试发送聊天、模型请求或屏幕图片。这不代表长时间真人操作或所有混合 DPI 多屏配置均已验收。

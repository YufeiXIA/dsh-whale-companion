## 这次的主要变化

- **完整版首次配置与启动**：先运行 `prepare-companion-profile.ps1`，即可在 profile 不存在时创建基础与网页配置，再链接桌宠和动画插件；启动脚本使用 DSH Desktop 自带入口。当前依赖目标为 DSH Desktop 0.2.0-rc.2 及其网页、搜索、读取与网页工具包，其他 DSH 版本尚未验证。
- **记忆与历史**：完整聊天留在本机归档；近期上下文与按需关键词检索配合，能从当前及其他未删除对话找回有来源的片段。偏好独立管理。「忘记」排除模型回忆，保留磁盘原文；删除对话后不再从该对话检索。检索不是向量语义搜索，无法保证找回所有内容。
- **更自然的回复动作**：主要聊天路径让模型结合整轮对话的含义选择动画，语音语气独立选择。没有合适动作时允许不选；新回复可以打断上一个展示动作。
- **固定主动陪伴周期**：默认每 5 分钟检查，可选 1～60 分钟或关闭。未回复不再叠加等待；忙碌、输入、免打扰、锁屏及睡眠时暂缓，恢复后不连续补发。
- **手动发图与看屏**：输入框支持选择或粘贴 PNG、JPEG、WebP 图片，预览后发送。自动看屏单独授权，仍只看主屏最上层窗口的可见区域；截图与摘要更关注正文、图表、报错和游戏局面。原始图片不写入聊天存档，文字观察可以随对话保存。
- **打断与输入**：实际输入给手动聊天让路，并停止主动语音。发送、关闭语音或切换对话可停止播放；仅聚焦输入框不会一直保持倾听动画。
- **持续睡眠**：面板与托盘都可开启，重启保留。闭眼抱尾巴循环与 Zzz 装饰持续显示，暂停自动移动、主动搭话、看屏和普通聊天语音。点击、拖动或打字不自动唤醒，手动叫醒后恢复原设置。
- **桌面移动与停靠**：自由跑动、自主乱跑和任务栏散步独立控制；窗口停靠跟随目标移动及缩放，空间不足时换到屏内放得下的位置。关闭、最小化、隐藏或完全移出屏幕后解除停靠并下落。
- **本地互动音频**：身体部位互动播放随包附带的短语音，不为每次触摸调用语音服务。聊天合成仍需要相应服务的 Key 与额度。
- **角色语气**：保留原有停顿、俏皮、亲近和情绪变化，更注意真实对话的连续性；提示词变化不保证每次回复都达到同一种风格。

## 版本差异

轻便版直接连接设置页中的模型服务，没有 DSH 或游戏控制。两版都能把相关历史摘录加入上下文；完整版还提供搜索和分页读取历史的工具，轻便版没有该工具。完整版通过 DSH 提供公开联网搜索和网页阅读，轻便版没有内置联网检索工具。

完整版 Fish Audio 聊天使用 PCM 流式播放，龙华及 Momo 聊天合成需要外部适配器。轻便版在线语音使用设置页配置的阿里百炼 Qwen 模型与音色，不提供 Fish 流式聊天或 Momo 声线选择；本地互动音频可直接播放。具体配置见 [轻便版说明](../lite/README.md)。

完整版的当前识图路径独立使用官方 DeepSeek API，需宿主环境变量 `DEEPSEEK_API_KEY`；轻便版在设置里选择识图服务。查看与聊天、语音、搜索有关的数据流，见 [SECURITY.md](../SECURITY.md)。

## 已知边界

发布前检查：完整版宿主 301 项、原生窗口逻辑 50 项、轻便版 31 项自动化测试通过。使用独立数据目录启动了干净的完整版 profile，并检查两版原生发布窗口、设置/游戏控件隔离、素材 HTTP 路由及睡眠视频实际解码；轻便版检查使用最终打包的可执行程序。未调用真实模型、语音服务或执行游戏操作。构建未使用代码签名证书，安装包会显示未知发布者。

- 当前仅发布 Windows x64，macOS 尚无可用包；[移植评估](macos-port.md)列出了下一阶段工作。
- 窗口、负坐标和跨屏几何有针对性检查；不同 DPI 的双屏实机行为仍需进一步验证。
- 语音首段时间受网络、服务排队和音频供给影响；流式实现不代表固定延迟或永不中断。
- 敏感窗口拦截与模型输出规则不能替代你对可见内容的判断；自动看屏默认关闭。
- 《杀戮尖塔 2》仅完整版提供实验性接入，现有演示不代表已完成人类玩家的完整合作通关。完整版另附[《星露谷物语》实验性适配与模组源码](../app/dsh-game-companion/STARDEW.md)，实际农场操作、游戏内气泡与语音尚未验收，不代表用户机器已安装该模组。
- 此次发布同步了后续本机改动。早期演示及更新记录中关于单击打开面板、未回复延长间隔、窗口一动就掉落的描述已过时。

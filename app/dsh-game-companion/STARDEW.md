# 《星露谷物语》实验性陪伴适配

完整版复用 [Sei 的 MIT 许可 SMAPI 伙伴模组](https://github.com/sei-studio/sei/tree/51774c7b9567a087aafdb33cc72a364a18da3bbf/native/stardew-mod)，由现有 DSH 宿主提供模型、桌宠聊天、记忆、气泡和语音通道。模组负责游戏角色、寻路、工具、背包和生存行为。源代码见 [`app/stardew-mod`](../stardew-mod)，保留了上游版本、许可与第三方说明；没有引入 Sei 的 AGPL 桌面应用。

当前提供接口与模组源码，实际农场移动、种植、浇水、收获、游戏中气泡和语音仍待端到端实机验证。此次发布没有在用户游戏中部署或验证这些行为。

## 准备

需要已安装的《星露谷物语》、兼容版本的 [SMAPI](https://smapi.io/)、PowerShell 7 和 .NET SDK。模组项目的目标要求以其工程文件与 SMAPI 依赖为准。先完成[完整版配置](../../README.md#安装)，关闭游戏，再从仓库根目录运行：

```powershell
pwsh ./tools/prepare-stardew-companion.ps1 -GamePath '<你的星露谷安装目录>'
```

脚本使用 `companion.config.json` 的数据目录设置；如需覆盖，可传 `-CompanionDataDir '<数据目录>'`，并让宿主使用同一目录。不要公开生成的模组 `config.json` 或宿主私有数据。

重新启动完整版宿主以加载适配接口，通过 SMAPI 启动游戏并进入独立测试农场，然后在桌宠面板选择 **连接 → 星露谷物语 → 让大肥鱼加入当前农场 → 继续合作**。普通 Steam 启动若未配置 SMAPI 启动项，不会加载模组；启动方式按 SMAPI 官方安装说明设置。

可以尝试明确的小任务，例如“帮我浇水，浇完跟着我”或“先收成熟的菜”。这些是待实机验证的使用方式。暂停会中止当前任务，已完成的游戏变化不会撤销；切换游戏、重新连接、重启宿主或换农场后需要重新确认并继续。

## 行为设计与限制

- 收获、浇水和跟随是默认任务类别；采集、砍树、购买、出售和物品转移需明确委托。缺工具、材料或路径失败时依据模组回执说明，不应在只有派单成功时声称完成。
- 任务在后台执行，聊天继续走现有桌宠。语音需开启并配置服务；模组中的农夫没有原生配音。若启用了全屏隐藏，桌宠在全屏游戏中可能不可见。
- 农场状态来自模组，无需自动截图。游戏公共聊天是观察数据，控制指令应在桌宠输入。
- 模组角色是可见 NPC 加影子农夫，并非第二个真正的联机玩家；首阶段以房主农场为接入点，多人房间其他玩家也需安装模组。
- 上游钓鱼使用等待和地点鱼表，并非完整钓鱼小游戏；战斗、NPC 对话、节日及特殊地图存在限制，不能据此承诺自主通关。
- 伙伴物品与钱包写入农场的 modData。测试应使用独立存档；模组会在存档写入前移除角色，之后重新加入。
- 模组仅监听 localhost，使用随机连接 token；正常安装关闭开发者指令。断线暂停，重新连接不自动恢复工作。

源代码、协议和来源说明见 [`app/stardew-mod/UPSTREAM.md`](../stardew-mod/UPSTREAM.md)。宿主与接口的自动测试不等同于实际农场行为验收。
